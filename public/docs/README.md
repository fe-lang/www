DO NOT EDIT THESE FILES

These files are generated by the Fe compiler (`fe doc` commands).
The source of truth is `crates/fe-web/assets/` in the compiler repo.

To regenerate:
  cd /path/to/fe
  cargo install --path crates/fe
  fe doc --builtins -o /tmp/docs json
  fe doc -o /tmp/docs bundle --with-css
  fe doc -o /tmp/docs static
  cp /tmp/docs/{fe-web.js,fe-highlight.css,styles.css,docs.json} /path/to/www/public/docs/
